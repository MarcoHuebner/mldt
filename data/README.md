# Reference data

`reference_manifest.json` records immutable analytical values and provenance.

`mcx_reference.json` is the standalone data source for the paper's qualitative
evaluation. It contains the nine 10,000-photon MCX spectra, their tissue
parameters, and the optical-property library used to turn those parameters into
wavelength-dependent coefficients. The JSON records the publication notebook's
SHA-256 digest so the extraction can be checked against its authoritative source.

`mcml_reference_1m.json` is generated by
`scripts/evaluations/resimulate_mcml_reference.py`. It keeps the same sample and
wavelength layout while storing a local MCML re-simulation at 1,000,000 photons
per wavelength, with a 20 cm deepest layer. Generate it on a machine with the
MCML command and a working CUDA device:

Its provenance records the MCX JSON filename and digest as the direct input,
along with the publication notebook filename and digest inherited from that
reference.

```bash
uv run python scripts/evaluations/resimulate_mcml_reference.py
```
